## 🔥 Featured Project (Flagship Level)

# 🌱 Automated Vegetation Monitoring using Multitemporal Satellite Images

<p align="center">
  <b>Deep Learning • Geospatial AI • Satellite Image Intelligence</b>
</p>

### 🎯 Problem Statement

Monitoring vegetation changes over time using satellite imagery is complex, manual, and time-consuming.

### 💡 Solution

Built an end-to-end AI system using **CF-HGNN-DP (Graph Neural Network-based architecture)** to automatically detect vegetation changes from multitemporal TIFF satellite images.

---

### ⚙️ Key Features

✔ Multitemporal TIFF image processing
✔ Vegetation gain / loss / no-change detection
✔ 2D + 3D geospatial visualization
✔ Interactive Streamlit AI dashboard
✔ Real-time performance metrics
✔ End-to-end deep learning pipeline

---

### 🧠 Tech Stack

**AI/ML:** PyTorch, Torch Geometric, Deep Learning
**Data Processing:** NumPy, SciPy, Rasterio, Scikit-image
**Visualization:** Matplotlib, Plotly
**Deployment:** Streamlit
**Language:** Python, Java (DSA)
